# architecture-lab

Песочница для системной проработки мобильной архитектуры: карта области,
разборы вопросов и код, который эти разборы показывает.

## Как устроено

- `architecture-map.md` — карта области. Источник при разметке и единственное
  место, где живёт формулировка границы области. Между разметками не правится.
- `q/` — разборы вопросов: по файлу на вопрос, рядом код или ADR, который его
  показывает.

Рабочее состояние живёт в GitHub Project `Architecture Mobile Knowledge`
(доска №9), а не в файле. Файл отвечает на вопрос «где у меня дыры», доска —
«над чем я работаю сейчас».

## Доказательство вместо стенда

CI-стендов здесь нет намеренно. Архитектурное решение проверяется тем, как оно
ведёт себя на длинной дистанции, а не прогоном за минуту в Actions. Поэтому у
каждого разбора в шапке строка `**Доказано:**`, а под ней — ссылки на файлы в
`q/<slug>/`: код, где решение и его альтернатива стоят рядом, граф модулей,
сценарий расхождения, ADR.

```bash
python3 tools/check-evidence.py
```

Проверка падает на двух вещах: нет строки `**Доказано:**` или файл, на который
она ссылается, не лежит в репозитории. Содержимое читает человек, не CI.

Разбор, который доказать нечем, помечается честно и проходит проверку:

```markdown
**Доказано:** нечем — рассуждение без стенда
```

## Цикл работы

Статусы на доске одинаковы для всех пяти областей знаний и описаны в
`pool-digest/scripts/workflow.py`. Статус называет работу, которая идёт сейчас,
а ворота проверяются на выходе из него:

| Статус | Что делается | Чтобы уйти дальше |
|---|---|---|
| `Map` | ничего, пункт карты не выбран | — |
| `Todo` | ждёт в пуле | — |
| `Pre-analysis` | пишется предразбор | комментарий с границами вопроса |
| `In Analysis` | пишется `q/<slug>.md` | файл с якорем `Issue: [#N]`, доказательство приложено |
| `Telegraph Page` | разбор заливается страницей | запись в `telegraph.json` |
| `Telegram Post` | пишется и уходит пост | комментарий с `message_id` |
| `Done` | закрыто | — |

Сторож в `pool-digest` ходит по доскам раз в час и откатывает карточку, которая
уехала вперёд без своего артефакта.

Разделы карты — родительские issue `#1`–`#7`, вопрос привязан к своему разделу
как sub-issue: прогресс по разделу считается сам.
