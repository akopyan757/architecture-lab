== A. Обязательное поле: зашёл и вышел, ничего не введя ==
Шаги: экран открыт → фокус в поле → blur → тап «Сохранить». Поле обязательное, пустое.

A1 плоская, валидация при создании состояния:
экран открыт              обязательное поле             «Сохранить» серая
фокус в поле              обязательное поле             «Сохранить» серая
blur                      обязательное поле             «Сохранить» серая
тап «Сохранить»           обязательное поле             «Сохранить» серая
  -> ошибка кричит на пустом экране, до любого действия пользователя

A2 плоская, валидация только в onChange:
экран открыт              —                             «Сохранить» серая
фокус в поле              —                             «Сохранить» серая
blur                      —                             «Сохранить» серая
тап «Сохранить»           —                             «Сохранить» серая
  -> ошибка не показана ни на одном шаге, кнопка серая без объяснения

фокус в поле              —                             «Сохранить» активна

тап «Сохранить»           обязательное поле             не отправлено
  -> ошибка появляется ровно на blur; submit отказывает и говорит почему

Второй заход на A3: пользователь не касался поля и сразу жмёт «Сохранить»
без оси submitted         —                             не отправлено
с осью submitted          обязательное поле             не отправлено
  -> submitted не выводится из touched: без неё submit так же глух, как A2

== B. dirty от факта правки против dirty от диффа ==

  -> состояния совпадают посимвольно: различить нечем, гейт выразить не на чем

== C. error хранить против выводить ==
C1 хранимый error: подстановка значения мимо пересчёта
